# Shortener 0.0.2

Лабораторная работа №2 по дисциплине «Методы и средства проектирования информационных систем и технологий».

Бездняков Александр, ИСТбд-42.

В этой версии реализованы создание коротких ссылок, просмотр списка и карточки, отказ при ошибочных данных. Платформа: Python 3.12.12, Flask 3.1.3, Jinja2 3.1.6, Gunicorn 23.0.0. Данные временно хранятся в JSON в одном контейнере.

## Запуск

```text
Репозиторий: https://github.com/lazer361/mispisit-shortener
Pull Request: https://github.com/lazer361/mispisit-shortener/pull/2
Образ: https://hub.docker.com/r/lazer361/mispisit-shortener

docker pull lazer361/mispisit-shortener:0.0.2
docker run --rm -p 8080:8080 lazer361/mispisit-shortener:0.0.2
```

Открыть http://localhost:8080.

## Страницы и действия

| Адрес | Назначение |
|---|---|
| `/` | Главная страница и переходы к функциям |
| `/links/new` | GET: форма, POST: создание ссылки |
| `/links` | Список ссылок |
| `/links/1` | Карточка демонстрационной записи |
| `/access-denied` | Пример отказа при неверном URL |
| `/s/ulstu` | Перенаправление на сайт УлГТУ |

## Проверка

1. Открыть форму создания ссылки.
2. Указать URL `https://ulstu.ru/`, название `Учебный портал`, короткое имя `study`.
3. Сохранить запись. Проверить карточку и новую строку в списке.
4. Открыть `http://localhost:8080/s/study`: сервер перенаправляет на исходный адрес.
5. Ввести URL `ulstu.ru` без протокола. Откроется страница отказа.
6. Повторно использовать короткое имя `study`. Система сообщит, что имя занято.

Короткое имя необязательно. Допустимы 3-32 латинские буквы, цифры, дефисы и знаки подчёркивания. Регистр учитывается. URL должен начинаться с `http://` или `https://`. Список общий; авторизация в этой версии не реализована.

## Данные

Файл `data/links.json` содержит демонстрационную запись с идентификатором 1. Форма дописывает новые записи в этот файл, список и карточка читают его. В файле хранятся идентификатор, название, исходный URL, короткий код и дата создания по времени Самары (UTC+4). Изменения живут в контейнере. После удаления контейнера командой с `--rm` следующий запуск образа снова содержит только демонстрационную запись. Постоянная база данных будет подключена в лабораторной работе №3.

## Локальная сборка

```sh
docker build -t shortener:0.0.2 .
docker run --rm -p 8080:8080 shortener:0.0.2
```

Приложение запускается одним процессом Gunicorn. Шаблоны находятся в `templates/`, оформление в `static/style.css`, проверка данных и работа с JSON в `links.py`, маршруты в `app.py`. Контейнер слушает порт 8080.
