# Shortener 0.0.3

Лабораторная работа №3 по дисциплине «Методы и средства проектирования информационных систем и технологий».

Бездняков Александр, ИСТбд-42.

Создание ссылок, список, карточка и отказ из версии 0.0.2 сохранены. Данные перенесены в PostgreSQL 16. Таблица создаётся приложением автоматически, при первом запуске на новом томе список пуст. JSON и демо-записи не используются.

## Запуск

```text
Репозиторий: https://github.com/lazer361/mispisit-shortener
Ветка: lab3
Pull Request: https://github.com/lazer361/mispisit-shortener/pull/3
Образ: lazer361/mispisit-shortener:0.0.3
Страница образа: https://hub.docker.com/r/lazer361/mispisit-shortener

git clone -b lab3 https://github.com/lazer361/mispisit-shortener shortener
cd shortener
docker compose up -d
```

Открыть http://localhost:8080. В Compose нет `build`: приложение запускается из готового образа `lazer361/mispisit-shortener:0.0.3`. Имя проекта `mispisit-bezdnyakov`, сервисы `app` и `db`. Данные PostgreSQL находятся в именованном томе `dbdata` по пути `/var/lib/postgresql/data`. Порт базы на компьютер не публикуется.

## Проверка сохранности

1. При первом запуске на новом томе открыть `/links`: список пуст.
2. Через `/links/new` создать ссылку: URL `https://ulstu.ru/`, название `Учебный портал`, короткое имя `study`.
3. Убедиться, что запись видна в списке и карточке.
4. Выполнить:

```sh
docker compose down
docker compose up -d
```

5. Снова открыть `/links`. Созданная запись должна остаться на месте. После повторных запусков заполненный список означает сохранённые ранее данные.
6. Повторно создать ссылку с именем `study`: будет отказ. Ввести URL `ulstu.ru` без протокола: также будет отказ.

Проверка проводится без удаления тома. Команды удаления тома в эту проверку не входят.

## Страницы

| Адрес | Назначение |
|---|---|
| `/` | Главная, версия 0.0.3 |
| `/links/new` | Форма и создание ссылки |
| `/links` | Список из базы |
| `/links/1` | Карточка первой созданной ссылки |
| `/access-denied` | Ошибочный сценарий |
| `/s/study` | Перенаправление после создания ссылки с именем study |

Список общий, авторизация пока не реализована. Короткое имя содержит 3-32 латинские буквы, цифры, дефисы или знаки подчёркивания; регистр учитывается. Без имени код генерируется автоматически.

## Хранение

Используется таблица `links`: `id`, `title`, `original_url`, `short_code`, `created_at`. Идентификатор формируется базой, короткий код имеет ограничение уникальности. Время хранится с часовым поясом и показывается по времени Самары, UTC+4. Параметры подключения читаются из переменной `DATABASE_URL`, заданной в Compose. Учебные значения пользователя, пароля и базы: `app`.

## Локальная сборка

```sh
docker build -t shortener:0.0.3 .
docker compose up -d
```

Платформа: Python 3.12.12, Flask 3.1.3, Jinja2 3.1.6, Gunicorn 23.0.0. Для базы добавлены `psycopg[binary]==3.3.6` и `typing_extensions==4.15.0`. Образ приложения собран для `linux/amd64` и `linux/arm64`. Теги предыдущих работ сохранены.
